# Commands
- `ALTER PUBLICATION ADD TABLE`
- `ALTER PUBLICATION DROP TABLE`
- `ALTER PUBLICATION RENAME TO`
- `ALTER SUBSCRIPTION {} ENABLE`
- `ALTER SUBSCRIPTION {} DISABLE`

1. Внести следующие изменения в публикацию
  - добавить таблицу в публикацию `alter publication add table`
  - удалить таблицу из публикации `alter publication delete table`
  - задать новое имя публикации `alter publication rename whatever`

  Указания. Для выполнения задания использовать команду ALTER PUBLICATION.

2. Внести следующие изменения в подписку:
  - отключить активную подписку `ALTER subscription DISABLE`
  - включить отключённую подписку,
  - задать новое имя подписки.
